## 什么是微信云开发

微信云开发是微信小程序官方提供的一站式后端服务，包含：

- **云数据库**：MongoDB 兼容的 NoSQL 数据库
- **云函数**：在云端运行的 Node.js 代码
- **云存储**：文件存储服务

**优势**：
- ✅ 无需购买服务器
- ✅ 无需搭建后端
- ✅ 自动弹性扩展
- ✅ 免费额度充足（个人开发者足够使用）

## 开通云开发

### 步骤 1：打开微信开发者工具

1. 打开微信开发者工具
2. 打开您的项目：`logistics-miniprogram/Goods-Monitoring-Programme`

### 步骤 2：开通云开发

1. 点击工具栏的 **"云开发"** 按钮
2. 如果没有开通，点击 **"开通"**
3. 同意服务条款
4. 等待环境创建完成

### 步骤 3：获取环境 ID

1. 进入云开发控制台
2. 点击左侧 **"设置"**
3. 找到 **环境名称** 和 **环境 ID**
4. **重要**：复制环境 ID，后面会用到

### 步骤 3：创建索引

为每个集合创建必要的索引以提高查询性能：

#### users 集合索引
- `phone`：唯一索引（手机号）
- `openid`：唯一索引（微信 openid）
- `role`：普通索引（角色）

#### orders 集合索引
- `tracking_no`：唯一索引（运单号）
- `status`：普通索引（订单状态）
- `created_at`：普通索引（创建时间，降序）

#### order_tracking 集合索引
- `order_id`：普通索引
- `created_at`：普通索引（创建时间，降序）

#### accessories 集合索引
- `name`：唯一索引（配件名称）
- `stock`：普通索引（库存数量）

#### accessory_logs 集合索引
- `accessory_id`：普通索引
- `created_at`：普通索引（创建时间，降序）

#### print_logs 集合索引
- `order_id`：普通索引
- `created_at`：普通索引（创建时间，降序）

### 步骤 4：设置权限

**重要**：合理的权限设置可以保护数据安全。

#### users 集合权限
```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

#### orders 集合权限
```json
{
  "read": "true",
  "write": "auth.openid != null"
}
```

#### 其他集合权限
```json
{
  "read": "true",
  "write": "auth.openid != null"
}
```

> **提示**：权限配置在集合详情页的"权限设置"中进行。

## 部署云函数

### 步骤 1：找到云函数目录

在项目根目录下有一个 `cloudfunctions` 文件夹，里面包含：

```
cloudfunctions/
├── user-auth/       # 用户注册
├── user-login/      # 用户登录
├── order/           # 订单管理
├── accessory/       # 配件管理
└── print-log/       # 打印记录
```

### 步骤 2：安装依赖

每个云函数目录中都有一个 `package.json`，需要安装依赖：

**方式 1：右键安装（推荐）**

1. 右键点击 `cloudfunctions` 文件夹
2. 选择 **"云函数批量上传并部署"**
3. 勾选 **"上传并部署"**
4. 等待部署完成

**方式 2：手动安装**

```bash
cd cloudfunctions/user-auth
npm install

cd cloudfunctions/user-login
npm install

cd cloudfunctions/order
npm install

cd cloudfunctions/accessory
npm install

cd cloudfunctions/print-log
npm install
```

### 步骤 3：上传并部署

对每个云函数文件夹：

1. 右键点击云函数文件夹（如 `user-auth`）
2. 选择 **"上传并部署：云端安装依赖"**
3. 等待部署成功提示

### 步骤 4：验证部署

部署成功后：

1. 在云开发控制台，点击 **"云函数"**
2. 您应该能看到已部署的云函数列表
3. 点击某个云函数可以查看日志

## 配置小程序

### 步骤 1：修改 cloud-api.js

打开 `utils/cloud-api.js`，找到初始化代码：

```javascript
// 替换为您的环境 ID
wx.cloud.init({
  env: 'your-cloud-env-id', // 这里替换为您的环境 ID
  traceUser: true
})
```

**如何获取环境 ID**：
1. 打开云开发控制台
2. 点击 "设置"
3. 复制 "环境 ID"（格式如：`cloud1-xxxxx`）

### 步骤 2：修改 app.js

打开 `app.js`，初始化云开发：

```javascript
App({
  onLaunch: function () {
    // 初始化云开发
    wx.cloud.init({
      env: 'your-cloud-env-id', // 替换为您的环境 ID
      traceUser: true
    })

    // 检查登录状态
    const userInfo = wx.getStorageSync('userInfo')
    if (userInfo) {
      this.globalData.userInfo = userInfo
    }
  },

  globalData: {
    userInfo: null,
    isLogin: false
  }
})
```

## 常见问题

### Q1：云函数部署失败？

**可能原因**：
- 网络连接问题
- 依赖安装失败
- 环境 ID 不正确

**解决方法**：
1. 检查网络连接
2. 重试部署
3. 查看云函数日志定位问题
4. 确认环境 ID 正确

### Q2：数据库操作权限不足？

**可能原因**：
- 云函数未正确配置权限
- 数据库权限设置过于严格

**解决方法**：
1. 检查数据库权限设置
2. 确认云函数返回的数据格式正确
3. 在云开发控制台查看详细错误日志

### Q3：如何查看云函数日志？

**操作步骤**：
1. 打开云开发控制台
2. 点击 "云函数"
3. 点击具体的云函数名称
4. 查看 "日志" 标签页

### Q4：如何调试云函数？

**方法 1：使用云开发控制台**
- 在云开发控制台中测试云函数
- 输入参数，查看返回结果

**方法 2：使用开发者工具**
- 右键点击云函数文件夹
- 选择 "查看云函数日志"
- 查看调用日志和错误信息

### Q5：如何删除云函数？

**操作步骤**：
1. 在云开发控制台中
2. 点击 "云函数"
3. 找到要删除的云函数
4. 点击 "删除"

> ⚠️ 删除云函数后，数据库中的数据不会丢失。

### Q6：如何备份数据库？

**方法**：
1. 在云开发控制台中
2. 点击 "数据库"
3. 选择集合
4. 点击 "导出数据"
